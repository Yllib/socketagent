# Generated Codex protocol

`src/generated/codex` contains protocol definitions exported by OpenAI Codex
0.157.1 with its `app-server generate-ts` and `generate-json-schema` commands.
OpenAI distributes Codex under Apache-2.0. The accompanying license is copied
from https://github.com/openai/codex/blob/rust-v0.157.1/LICENSE.

The generator preserves the exported TypeScript files, selects their dependency
closure, builds a method map, and combines the v2 JSON schema with the outer
protocol's initialization response. See the generated manifest for version and
content hashes. No T3 Code implementation was copied.
